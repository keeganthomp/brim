---
title: Quickstart
description: Make a verified local payment, then attach your own agent.
---

Use **Node 24** and **Docker Compose v2** from a Brim checkout. All local SOL and USDC are fake.

## Start Brim

```bash title="Terminal 1"
npm ci
npm run dev
```

The first run can take a few minutes. It creates a funded Surfpool vault and starter policy, then starts the dashboard at `http://localhost:3000` and the paid API on port `4020`.

## Pay for the report

Open the dashboard in **Local workspace** and choose **Make test payment**. This uses the starter agent to pay $0.04 for the included report. Wait for the independently verified payment in **Activity**; indexing may finish after the resource response.

The command-line alternative in another terminal is:

```bash title="Terminal 2"
npm run demo:payment
```

Its final JSON record reports `status: "settled"`, the transaction signature, and `ledgerRows: 1`. The runner checks the vault debit, merchant credit, finalized program event, and deduplicated ledger. It makes a new payment; do not rerun it merely to check an earlier payment's status.

## Register your own agent

1. Keep its existing scoped Ed25519 keypair, or run `npm run agent:key -- --out .brim/research-agent.json`. The helper writes a new mode-`0600` file and prints only its public key and path.
2. Choose **Local workspace → Add policy**. Paste only the **public key** and set a per-payment cap and 24-hour budget. A $1 cap and $50 budget cover the report. Advanced controls hold spacing and recipients.
3. Choose **Add policy** and wait for on-chain confirmation. The generated test owner registers the policy; your agent appears in the list.
4. Open the policy's **Code setup**. Use **Copy setup** and **Check connection**, then follow the [SDK command](/docs/sdk/#register-your-agent-locally) or [MCP key-file setup](/docs/mcp/#connect-your-own-local-agent) to pay the report with that key.

All agents on this vault share its public vault config but retain separate private keys and policies. Local SDK/MCP `/report` payments index automatically after finalized verification. Check connection is a setup check, not a guarantee of future settlement.

Local funding and freeze controls stay read-only; Demo workspace simulates them. To create and fund a vault or freeze an agent through an actual owner wallet, follow the [configured Live flow](/docs/production/#follow-the-owner-wallet-flow). That requires a preexisting public program; the dashboard does not deploy one.

## Stop the stack

Ctrl-C stops the apps while Surfpool and Postgres keep running. `npm run local:down` removes the test chain container and preserves Postgres data. The next startup recreates the chain with saved local keypairs; retained ledger rows can describe the earlier local chain.
